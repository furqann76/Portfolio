# Portfolio

Personal developer portfolio for Furqan Hafeez: a single-page site built with plain HTML, CSS and JavaScript (no framework or build step).

**Live site:** https://furqann76.github.io/Portfolio/

## Contents

- Hero, about, skills, projects (with category filter), experience, education and contact sections
- Print-friendly CV view
- Responsive layout with scroll-reveal animations
- Contact form that opens the visitor's email client (`mailto:`), no backend

## Run locally

```bash
python3 -m http.server
```

Then open http://localhost:8000. Everything lives in `index.html`.

## Deployment

Hosted on GitHub Pages from the `main` branch.
